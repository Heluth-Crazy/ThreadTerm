What changes, and why

One top row instead of two. The 36 px title bar and the session header merge into a single unified toolbar: title and subtitle (project · branch), a Run activity field, and the agreed Workbench views as one segmented control. Windows min/max/close stay on the right, so Snap and the usual hit targets still work.

A source-list sidebar from top to bottom. Computers are sections (This PC, studio-pc), with sentence-case headers, tinted icons and one-line rows whose status sits at the trailing edge. The search field is the command palette. New session and the sidebar toggle sit in the sidebar header, as in Mac apps.

Mac controls everywhere. Push and popup buttons, switches, segmented controls, translucent menus with Ctrl shortcuts, a Spotlight-style palette, a sheet for New session, and Settings as a System Settings window with a sidebar instead of 11 overflowing tabs.

Two looks, one token set. Flush (macOS 15) is denser and suits terminals. Floating (macOS 26) puts the sidebar, inspector and toolbar groups on glass panels. Both are geometry only: the palette switch shows that the current warm palette and the theme packs still recolor everything.

Windows-specific choices. Segoe UI Variable stands in for SF Pro, which can't ship on Windows. Shortcuts say Ctrl, not ⌘, and "Show in Explorer" replaces "Reveal in Finder". The sidebar can use real Mica through Electron's backgroundMaterial on Windows 11. Windows 10 falls back to the solid tint shown here.

Cursor · Agents (exploration, 2026-11-14). Cursor 3's Agents Window translated to ThreadTerm: a monochrome palette (Cursor mono), hairlines instead of filled tracks, ghost controls, New session on top of a flat sidebar with sessions grouped by project and their change stats, a one-line toolbar title, the prompt as a full-width card, and a bordered composer whose agent and model pickers lead, with a round monochrome Send. Tabs, the panel and every feature stay as agreed. The Start screen shows the new-session composer in both looks.

Cursor-referenced surfaces (2026-11-14). The owner kept the project list, tabs and the rest, and asked for Cursor's design in Start, Git and file editing, plus Cursor's Design Mode notes. Start: agent and model lead, then project, branch and computer, recent sessions below. Git review: every changed file stacked in one scroll with per-file and per-hunk Discard / Stage / Comment; Source Control: branch and push as ghost chips, Commit inside the message field. Editor: breadcrumbs, ghost actions, change bars and an agent-change bar in the gutter. Design mode: Annotate in the browser toolbar, a tool row, pins, a note card with the element, a CSS list and Save / To chat, and Send with a count.
