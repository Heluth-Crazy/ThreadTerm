# 大型模块拆分与废弃代码收口

## Goal

在功能和性能整改稳定后，拆分最难维护的大文件，统一重复规则并删除确认无用的旧代码，降低后续修复互相影响的概率。

## Requirements

- Rust bridge 按服务生命周期、状态投影、预览、命令入口拆分。
- `Shell.jsx` 先完成类型化，再按终端创建、输入、尺寸、恢复、渲染生命周期拆分。
- `TerminalManager` 按工作台模型、命令注册、布局和对话框协调拆分。
- ANSI 文本清洗只保留一个经过测试的实现。
- 删除 `replayRecentOutput` 等零读取旧参数。
- 删除确认无生产引用的实验渲染脚手架。
- 每一步只移动职责，不顺带改变交互或协议。
- 不进行基础依赖 major 升级。

## Acceptance Criteria

- [x] 拆分前后公开函数、命令和消息格式不变。
- [x] 每个拆分提交可独立回滚。
- [x] 无循环依赖。
- [x] 死代码搜索为零且相关测试同步清理。
- [x] 全量行为测试、性能基线和构建结果不回退。
