- Deep file `deep/nested/folder/target.ts` auto-revealed on first Files open. After Collapse all, File bar > Reveal in Files left the file absent from the tree and unfocused (`rowVisible:false`, `focused:false`).
- Cause: file-reveal only sets toolsOpen (or sends view:files in embedded mode), never a target or request identity. ExplorerView auto-reveal depends on activePath/load, so the already-active path does not re-run after collapse/scroll. Its focus effect targets the currently available tabindex row before async ancestor loading, rather than awaiting the requested row. Owner-session previews also do not become activeFilePath. Missing paths are never resolved to a parent; ancestor load errors are swallowed.

Fixture-only issues identified with screenshots/traces: missing app-shell main grid wrapper narrowed the fixture to 244px; corrected test wrapper. Playwright auto-scroll before a context click can deliver a late scroll event that dismisses ContextMenu; explicitly settle the target scroll before right-click. No product fix guessed for harness failures.
