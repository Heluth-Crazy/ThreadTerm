# 项目审查整改总计划 · Technical Design

## Program Boundaries

本任务是计划与集成父任务，不直接承载大段实现。每个子任务必须能独立验证、
独立回滚，并维护现有桌面端、移动端和桥接协议的跨层契约。

## Dependency Order

```text
安全等价基础
  ├─> 手机连接生命周期
  │     └─> 手机输出连续性与内存
  │             └─> 局域网安全
  ├─> 终端运行可靠性
  ├─> 后台 IO 性能
  ├─> 前端稳定性
  └─> 输出性能

所有阶段 ─> 真实场景质量门禁
最后 ─> 大模块拆分与废弃代码收口
```

## Cross-Task Contracts

- 手机协议新增字段必须可识别旧消息，并通过明确版本拒绝不兼容客户端。
- 任何内存上限必须有用户可见的截断提示和重新同步路径。
- 任何“后台化”写入必须定义队列满、应用退出和写入失败行为。
- 任何渲染降载必须保证隐藏界面仍摄取真实状态，只减少重复绘制。
- 任何超时都必须有确定的重新注册或重新同步方式，不能静默丢失。
- 加密方案在实现前必须通过手机浏览器证书/信任可用性验证。

## Rollout

- Wave 1：连接生命周期、输出连续性、测试门禁。
- Wave 2：局域网安全、终端运行可靠性、后台 IO。
- Wave 3：前端和输出性能。
- Wave 4：架构拆分与清理。

每个 Wave 完成后运行全量门禁并保留可回滚边界。
