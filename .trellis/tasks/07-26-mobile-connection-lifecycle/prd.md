# 手机连接状态与自动恢复

## Goal

让手机显示的连接状态可信：网络断开能及时发现，权限撤销后停止重试，健康连接在应用回前台时不被无谓重建。

## Requirements

- 健康连接持续交换轻量存活信号。
- 连续 15 秒收不到电脑回应时，手机进入“连接已中断”并开始退避重连。
- 收到电脑回应后恢复“已连接”，不要求用户刷新页面。
- 电脑端撤销设备时，先向该设备发送“权限已撤销”终态，再关闭连接。
- “权限已撤销”状态不得继续自动重连；重新配对后才能恢复。
- `visibilitychange`、`online`、`pageshow` 只检查连接，不主动摧毁健康连接。
- 断网重连继续使用有上限的退避，避免网络抖动时高频请求。
- 旧版服务端没有新终态消息时，手机仍按普通断线兼容处理。

## Acceptance Criteria

- [x] 静默断网 15 秒内显示断线。
- [x] 网络恢复后自动重连并取得最新快照。
- [x] 健康连接前后台切换不新增 WebSocket。
- [x] 撤销设备后显示明确原因且重连次数不再增长。
- [x] 重新配对可以从撤销状态恢复。
- [x] fake timer 单测和移动端 E2E 覆盖上述状态。
