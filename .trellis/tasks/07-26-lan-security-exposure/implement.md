# 移动端安全接入 · Implementation Plan

## Step 1 — 收起明文入口

- [x] impact bridge start/status/settings/persist。
- [x] 新安装与迁移后的默认绑定均为本机。
- [x] 启动命令拒绝任何非本机监听地址。
- [x] 删除已经无法使用的网卡地址探测和直接局域网开放代码。
- [x] 停止服务时继续立即断开已有连接。

## Step 2 — 安全隧道配对

- [x] 用户已确认采用成熟 HTTPS 安全隧道，不自行设计加密协议。
- [x] 设置页改为填写完整 HTTPS 隧道地址。
- [x] 不提供安全地址时不展示可供手机扫描的二维码。
- [x] 二维码和配对响应绑定稳定的电脑身份。
- [x] 长期凭证只在配对响应中下发，不再支持网址 token。

## Step 3 — 浏览器与凭证保护

- [x] 手机端拒绝远程 HTTP/WS，只允许本机明文开发地址。
- [x] 快照、配对和实时连接均拒绝来源不一致的浏览器请求。
- [x] 手机收到不同电脑身份时清除凭证并要求重新配对。
- [x] 凭证改为浏览器会话级保存，并清理历史永久凭证。

## Validation

- [ ] 抓包检查。
- [x] 冒充电脑身份、重复使用和过期二维码自动测试。
- [x] 默认本机、拒绝远程明文、同源限制和停止断连自动测试。
- [x] 一次性口令、重放、过期、权限降级和撤销自动测试。
- [x] HTTPS 地址、电脑身份和浏览器会话凭证自动测试。
- [ ] 两类真机浏览器验收。
- [x] 全量门禁和安全复核。

## Decision Gate

- [x] 用户已确认继续全部整改；实现选择成熟 HTTPS 安全隧道，因为手机浏览器对
  临时本地证书的信任体验不稳定，且项目不应自行拼装密码协议。
