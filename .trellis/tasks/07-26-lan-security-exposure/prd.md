# 局域网访问安全与显式开放

## Goal

默认不把 ThreadTerm 暴露给局域网；用户明确开启手机访问后，终端内容和长期凭证不得以明文在网络中传输。

## Requirements

- 初始默认只监听本机地址。
- 设置页提供明确的“允许局域网设备连接”开关和风险说明。
- 开启前必须二次确认；关闭后立即停止局域网监听并断开外部设备。
- 配对二维码只能包含短期、一次性信息，不暴露长期设备凭证。
- 终端内容、输入和长期凭证在局域网传输时必须加密。
- 手机必须能确认正在连接的是二维码对应的电脑，而不是同网冒充服务。
- 方案必须能在主流 iOS/Android 浏览器实际使用。

## Acceptance Criteria

- [ ] 新安装默认无法从其他设备访问。
- [ ] 明确开启后手机可完成配对和加密连接。
- [ ] 抓包不能读出终端文本、输入或长期凭证。
- [ ] 中间人替换电脑身份时配对失败。
- [ ] 关闭局域网开关后现有外部连接立即结束。
- [ ] 本机开发和桌面内嵌访问保持可用。
