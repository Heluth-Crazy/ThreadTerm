# 移动端安全接入

## Goal

ThreadTerm 不再直接向局域网开放。桌面服务始终只在当前电脑内运行，手机访问必须经
Tailscale Serve、Cloudflare Tunnel 等成熟 HTTPS 安全隧道，避免终端内容、输入和
设备凭证在网络中明文传输。

## Requirements

- 新安装、升级迁移和手动启动都只能监听 `127.0.0.1`。
- 设置页接受完整的 HTTPS 隧道地址，不再提供“直接开放局域网”选项。
- 配对二维码只包含短期一次性口令、权限范围和电脑身份，不包含长期设备凭证。
- 长期凭证只通过 HTTPS 配对响应下发，不能再放进网址。
- 手机请求只能访问二维码对应的同源服务，并校验服务返回的电脑身份。
- 手机长期凭证只保留到当前浏览器会话结束，关闭会话后需重新配对。
- 方案必须能在主流 iOS/Android 浏览器实际使用。

## Acceptance Criteria

- [x] 新安装和旧设置迁移后均无法直接从其他设备访问。
- [x] 非本机明文地址在桌面端和手机端都会被拒绝。
- [x] HTTPS 隧道地址可生成带电脑身份的配对二维码。
- [x] 网址 token、任意跨域请求和身份不匹配连接均被拒绝。
- [x] 手机凭证不再永久保存在浏览器中。
- [ ] 经真实 HTTPS 隧道后手机可完成配对和加密连接。
- [ ] 抓包不能读出终端文本、输入或长期凭证。
- [x] 自动测试确认替换电脑身份时配对失效并清除凭证。
- [x] 停止桌面服务后现有外部连接立即结束。
- [x] 本机开发和桌面内嵌访问保持可用。
