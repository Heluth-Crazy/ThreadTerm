# 移动端安全接入 · Technical Design

## 方案选择

采用成熟 HTTPS 隧道作为手机入口，ThreadTerm 本身不签发证书，也不自行实现加密协议。
推荐入口包括 Tailscale Serve 与 Cloudflare Tunnel，它们把公网或私网 HTTPS 地址
反向代理到当前电脑的 `127.0.0.1` 服务。

原因：iOS Safari 与 Android Chrome 对临时自签证书的信任和安装流程并不一致；
成熟隧道已经解决证书、加密和更新问题，项目无需承担自研密码协议风险。

## 暴露范围

Bridge 无论从设置页、启动恢复还是后端命令启动，都只接受 `127.0.0.1`。
旧版本保存的 `0.0.0.0` 会在启动时迁回本机地址。设置页不再展示局域网直连开关，
只接受安全隧道提供的完整 HTTPS 地址。

## Pairing

一次性配对口令继续保持短时有效和单次消费。二维码额外携带电脑身份，手机在配对
响应和后续快照中都校验该身份。长期 token 仅由 HTTPS 配对响应下发，服务端仍只
保存其 hash；手机仅在当前浏览器会话保存，关闭会话后重新配对。

浏览器发起的配对、快照和实时连接必须同源。服务端不再接受网址中的 token，
手机端也拒绝任何非本机的 HTTP/WS 地址。

## Rollback

安全隧道在真机上无法稳定使用时，不允许恢复直接局域网明文入口。桌面本机功能
保持可用，手机入口维持关闭，直到隧道或浏览器兼容问题解决。
