# 手机终端输出连续性与内存边界

## Goal

保证手机看到的是当前电脑运行实例的连续终端画面，同时让长期运行的手机页面内存有明确上限。

## Requirements

- 电脑每次启动生成新的运行标识，所有终端快照和增量输出携带该标识。
- 手机发现运行标识变化时清空旧序号并重新取得快照，不再冻结在旧画面。
- 同一运行标识内发现输出缺段时自动请求当前终端完整画面。
- 持续输出期间，任务列表和状态最迟 1 秒同步一次。
- 每个终端按实际字节而非消息条数限制历史内存。
- 默认每卡保留最近 4 MiB、全局最多 32 MiB；超出时丢弃最旧历史并插入一次“更早内容已省略”提示。
- 卡片删除、归档或电脑运行标识变化时释放对应缓存。

## Acceptance Criteria

- [x] 电脑端重启而手机页面不刷新时，新输出仍能在自动恢复后显示。
- [x] 人为制造序号缺口后手机请求并应用完整快照。
- [x] 持续输出时状态同步间隔不超过 1 秒（假时钟持续更新回归测试）。
- [x] 大输出后单卡和全局内存不越界。
- [x] 删除卡片后对应缓存立即释放。
- [x] 截断提示只出现一次且不伪装成真实终端输出。
