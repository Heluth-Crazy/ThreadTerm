# 工作台界面稳定性与渲染性能

## Goal

持续输出时工作台保持稳定：用户准备点击的卡片不跳走，只刷新真正变化的区域，刷新反馈和长对话滚动保持顺畅。

## Requirements

- 运行中的卡片按稳定顺序显示，不因每次输出更新时间而反复交换位置。
- 任务开始、结束、手动排序或重新进入列表时可以重新计算顺序。
- 单个终端输出只刷新该终端及必要状态，不重绘所有持久终端。
- 刷新按钮的加载图标必须随状态变化。
- 通知中心关闭时不计算完整标签映射。
- 长 Codex 对话收到新内容时不重建所有历史行。
- 隐藏的 Codex 卡继续接收真实消息，但减少不可见区域绘制。
- 普通鼠标点击只聚焦终端；仅在表面确实异常时执行完整恢复。
- 所有优化不得造成旧标题、旧图标、漏消息或错误卡片状态。

## Acceptance Criteria

- [ ] 两张持续输出卡 60 秒内 DOM 顺序不抖动。
- [ ] 单卡输出时其他 TerminalView/Shell 渲染次数保持不变。
- [ ] 刷新图标能显示和结束 loading。
- [ ] 1000 条 Codex 历史下流式输出保持交互流畅。
- [ ] 隐藏再恢复的卡片消息完整。
- [ ] 点击终端仍能聚焦，异常表面仍可恢复。
