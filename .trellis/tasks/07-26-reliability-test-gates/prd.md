# 真实断连与多任务质量门禁

## Goal

让最容易出问题的真实场景进入自动检查，不再只依赖模拟连接和开发者手工记忆。

## Requirements

- 保留已完成的最小 Windows CI。
- 增加手机真实 WebSocket 断开、退避、恢复和重新同步测试。
- 增加电脑端重启标识变化与输出缺口恢复测试。
- 增加多终端并行输出、不同消费速度和删除卡片测试。
- 增加窗口最小化、恢复和 float/main 跨窗口水位测试。
- 增加撤销设备后停止重连测试。
- 区分稳定门禁与耗时真机/压力任务；PR 门禁不得长期随机失败。
- 发现测试共享状态竞态时只修测试隔离，不用串行全部测试掩盖问题。

## Acceptance Criteria

- [x] PR 自动运行 typecheck、Vitest、Cargo test。
- [x] 真实 bridge 测试不使用 MockWebSocket。
- [x] 多卡并行测试能覆盖 ACK、水位、删除和重连交错。
- [x] 同一门禁连续运行 10 次无随机失败。
- [ ] 真机/长时压力测试有明确手工或定时运行记录。
