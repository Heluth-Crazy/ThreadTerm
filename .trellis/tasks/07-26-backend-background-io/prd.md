# 后台网络探测与会话目录性能

## Goal

打开手机设置、生成二维码和浏览历史会话时不再卡住界面或闪出命令窗口，大型历史目录仍能逐步返回完整结果。

## Requirements

- Windows 网络地址查询不得显示控制台窗口。
- 网络地址结果缓存 30 秒，并提供显式刷新。
- 网络查询和目录扫描不得占用负责处理连接/界面请求的异步线程。
- Claude 大会话文件只读取识别元数据所需的开头内容。
- Gemini/Claude 大目录按最近修改时间分页，不整批读取所有文件。
- 分页不得静默遗漏旧会话；用户继续加载时仍能取得后续结果。
- 没有手机连接时，不为移动端重复补全和序列化全部卡片。
- 有手机连接时，通知变化不得无条件触发每卡大缓冲复制。

## Acceptance Criteria

- [x] 连续打开状态页 10 次只执行一次网络查询。
- [x] 手动刷新立即重新探测。
- [x] 网络查询耗时 2 秒时其他 bridge 请求仍可响应。
- [x] 50 MiB Claude 会话文件只读取有界前缀。
- [x] 10,000 个会话文件可在分页内返回且界面不冻结。
- [x] 无手机订阅时移动快照补全计数为零。
