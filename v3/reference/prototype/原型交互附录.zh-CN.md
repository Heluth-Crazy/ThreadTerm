## 0. 产品定位

### 0.1 产品是什么

个人开发者的**本地项目绑定工作台**：在同一产品里管理多个本地项目、每个项目下的 Git 工作树、以及挂在工作树上的 Agent / Shell 会话（Claude / Codex / Gemini / Shell）。

不是 IDE，不是云端 Agent 编排，不是 SaaS 运营后台。

### 0.2 卖点（必须在界面上可感知）

1. **多 Agent**：Claude / Codex / Gemini / Shell，品牌图标贯穿侧栏、工作区、卡片。
2. **工作树一级**：侧栏项目 → 工作树 → 会话；每棵树有独立状态。
3. **状态感知**：一眼看出哪些会话在跑、哪些在等你、哪些已结束或目录不可用。

### 0.3 原型边界

- 纯静态单页，hash 路由。
- 全部操作为本地演示：不执行 Shell / AI、不访问真实文件、不付款、不发网络请求。
- 底部状态栏常驻：「离线运行 · 不连接真实终端 · 2026.09」。

## 1. 全产品概念与合同

### 1.1 对象层级

```
项目 (project)
  └─ 工作树 / 分支 (worktree)
        └─ 会话 (session)：Agent 或 Shell 的一条终端记录
              └─ 待处理事项 (attention episode)：挂在会话上的「需要你」条目
```

关注（星标）是会话上的**正交标记**，不是状态，也不是待处理队列。

### 1.2 状态五态（全产品统一）

| 状态码 | 用户可见文案 | 颜色语义 | 含义 |
|---|---|---|---|
| `needs` | 需要你 | 琥珀 | 会话在等用户决定（待确认 / 待输入 / 待复核） |
| `running` | 运行中 | 薄荷 | 会话在推进 |
| `failed` | 失败 | 红 | 如连接中断 |
| `stalled` | 停滞 | 蓝 | 目录缺失、长时间无输出等**提示**，不等于失败 |
| `ended` | 已结束 | 灰 | 只读，不能再输入 |

二级文案（待确认 / 待输入 / 待复核 / 目录缺失）只出现在 Inbox 徽章、详情、进行中会话 chip 等细处，**不另开第六态**。

工作树状态 = 其下可用会话的聚合，优先级：需要你 > 失败 > 运行中 > 停滞 > 已结束。  
项目状态 = 其下未移除工作树的聚合，同一优先级。

### 1.3 已关注 vs 待处理 vs 进行中

| 概念 | 定义 | 进出条件 |
|---|---|---|
| **已关注** | 用户星标的会话 | 只随星标增删；任意五态都可在列表里 |
| **待处理** | Inbox 可处理事项：待确认 / 待输入 / 失败 / 待复核 | 标已处理或忽略后离开队列。停滞**不进**主队列 |
| **进行中** | `running ∪ needs ∪ failed ∪ stalled` | 会话从运行中变为待处理时**行仍在**，只换徽章。`ended` 不进入 |

禁止：把已关注当成待处理队列；禁止进行中列表在「运行中 → 需要你」时把行删掉。

### 1.4 会话可用性

| 条件 | 结果 |
|---|---|
| 运行中 / 需要你 / 失败（目录仍在） | 可打开工作区，可输入（失败会话仍可进工作区查看） |
| 用户确认「结束会话」 | 状态覆盖为已结束；不可输入；「打开」改为去所有终端看记录 |
| 工作树 `missing` 或已被模拟移除 | 不可继续；去所有终端看记录；浮窗打不开 |

`openSession` 合同：可用 → `#/workspace/<id>`；不可用 → `#/terminals` 并高亮该卡 + Toast。

## 15. Toast 与可及性播报

Toast 约 3.2 秒，与 `#live` 同步。主要文案：

|---|---|
| 创建会话 | 已创建 {名}，直接进入对应会话 |
| 结束会话 | 演示会话已结束；历史和输出仍可查看 |
| 不可用仍点打开 | 已结束 / 目录不可用，可在所有终端中查看记录 |
| 关注/书签/规则/重命名/导出 | 已更新… / 已加入本地书签 / 已保存规则 |
| 并排 | 已并排 {名} / 已退出并排 / 最多 2×2 / 只能并排本工作树 |
| 置顶/弹出/收起浮窗 | 已从并排置顶为浮窗 / 弹出为浮窗 / 浮窗已收起 / 不是系统窗口 |

| 命令 | 仅模拟输入了选中的命令 |

## 18. 验收清单

对照本说明书，下列必须同时成立：

1. **导航不串**：点项目名 → 项目简报；点工作树 → 分支简报；点会话 → 工作区（不可用 → 所有终端）。
2. **无历史一级页**：侧栏无「历史记录」；`#/history` 落到所有终端；「查看记录 / 查看全部 / 最近活动」均带筛选与高亮。
3. **简报骨架**：任意项目、任意分支（含 main 全结束、clean、缺失树）三槽位置与高度一致；空数据仍占槽，溢出在槽内滚。
4. **已关注正交**：只随星标变化；运行中变待处理时不从已关注消失；「关注为空」演示不清待处理数字。
5. **进行中不丢行**：运行中 → 待处理时行仍在，仅徽章从「运行中」改为待处理细类或「N 个待处理」。
6. **并排合同**：必须先从本树选择器选会话；最多 2×2；点格子切焦点（iris +「当前」）；置顶/弹出从格子移除并开浮窗；拖标题条重排；换会话可对调。
7. **Inbox 唯一队列**：筛选五类不含停滞；停滞仅底栏说明；行上查看/⋯/关注/已处理/忽略行为符合第 4、13、14 章。
8. **用量卡**：项目/分支主页用量为指标带右侧一张卡（今日、近 7 日并排 + spark）；项目页卡头「明细」打开筛选弹层；checkout 合计与项目页对齐。
9. **工作区控件齐**：返回、项目/分支 chip、三 tab、会话 chip、并排/退出、切换会话、星标、结束、抽屉内每一块（文件筛选、命令模拟、关注/重命名、书签、保存预设）。
10. **对话框可取消**：每个对话框有取消或等价关闭；危险操作有确认文案；添加关注取消不改集合。
11. **键盘**：Ctrl+K、Ctrl+Alt+N、Esc、对话框 Tab 循环、Composer Enter 提交 / Shift+Enter 换行。
12. **离线**：全部操作为本地演示；底栏常驻离线声明；无外网请求、无真实命令。
