# v0.3 AI Session State Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Make AI CLI cards easier to understand by showing provider session state and surfacing missing CLI diagnostics in card and notification UI.

**Architecture:** Keep provider discovery and PTY lifecycle unchanged. Add a small frontend helper that derives AI CLI state from the existing `TerminalCard` metadata and output, render that state in card/focused terminal headers, and use the same helper to improve error notification copy when a provider CLI is missing.

**Tech Stack:** React 18, TypeScript, Zustand, react-i18next, Vitest, Tauri PTY events.

---
