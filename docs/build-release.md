# Build & Release Guide

This guide covers building the current ThreadTerm Tauri desktop app.

## Supported Targets

- macOS desktop app and bundles generated by Tauri.
- Windows desktop app and installer bundles generated by Tauri.
- Linux may build, but global shortcut and always-on-top behavior depends on the desktop environment.

## Requirements

Common requirements:

- Node.js 22 LTS and npm 10+
- Rust toolchain from <https://rustup.rs>
- Tauri CLI: `cargo install tauri-cli`

macOS requirements:

- macOS 10.15+
- Xcode Command Line Tools
- Apple Developer account if release signing/notarization is required

Windows requirements:

- Windows 10/11 x64
- Visual Studio Build Tools 2022 with `Desktop development with C++`
- Windows 10/11 SDK

## Local Verification

Run these checks before packaging:

```bash
npm install
npm run typecheck
npx vitest run src/components/terminal/TerminalEventBridge.test.tsx src/components/terminal/providerSession.test.ts src/components/terminal/useProjectGroups.test.ts src/stores/overlayStore.test.ts src/stores/terminalStore.test.ts src/theme/themePacks.test.ts
npm run build
cargo check --manifest-path src-tauri/Cargo.toml
cargo test --manifest-path src-tauri/Cargo.toml pty::tests
```

## Development Build

Run the Tauri app in development mode:

```bash
npm run tauri:dev
```

This command starts Vite through `src-tauri/tauri.conf.json` and launches the desktop shell.

## Production Build

Build the frontend and desktop bundles:

```bash
npm run tauri:build
```

Tauri writes platform-specific output under `src-tauri/target/release/bundle/`.

On macOS, typical bundle output includes `.app`, `.dmg`, or `.app.tar.gz` depending on the installed Tauri bundler support.

On Windows, typical bundle output includes installer artifacts under `src-tauri\target\release\bundle\`.

## Build Configuration

Relevant files:

- `package.json`: npm scripts and frontend dependencies.
- `vite.config.js`: three Vite HTML entries, `index.html`, `selector.html`, and `float.html`.
- `src-tauri/tauri.conf.json`: Tauri app window, bundle target, icon, and frontend build commands.
- `src-tauri/Cargo.toml`: Rust backend dependencies and release profile.

The current desktop app keeps one configured Tauri main window. Overlay selector and floating terminal windows are created at runtime by `src-tauri/src/overlay.rs`.
