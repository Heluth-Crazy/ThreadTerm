# Documentation

Welcome to the OpenWork (OpenWork) documentation.

## Overview

OpenWork provides a web-based and desktop interface for Claude Code, Cursor CLI, and Codex. This documentation covers installation, development, building, and troubleshooting.

## Key Features

- **Web-based UI** - Access from any device via browser
- **Desktop App** - Native applications for macOS and Windows
- **Multi-CLI Support** - Works with Claude Code, Cursor CLI, and Codex
- **Responsive Design** - Works on desktop, tablet, and mobile
- **Session Management** - Resume and manage conversations

## System Requirements

### Web Application

- Node.js v22+
- Modern web browser (Chrome, Firefox, Safari, Edge)

### Desktop Application

| Platform | Requirements |
|----------|--------------|
| macOS | macOS 10.15+ |
| Windows | Windows 10/11 (64-bit) |
| Linux | Ubuntu 20.04+ or equivalent |
