# 首次使用指南

这份指南覆盖 ThreadTerm 前五分钟最重要的流程。

## 1. 启动桌面应用

```bash
npm install
npm run tauri:dev
```

PTY 会话、全局快捷键、浮动窗口和系统通知都需要在 Tauri 桌面应用中验证。
前端 Vite 预览适合调 UI，但不能完整验证桌面能力。

## 2. 创建第一张卡片

1. 点击 **新建**，或按 `Cmd/Ctrl + N`。
2. 选择项目目录。
3. 选择终端类型：
   - **Shell**：普通项目 shell。
   - **Claude**、**Codex** 或 **Gemini**：需要对应 CLI 已安装并在 `PATH` 中。
   - **自定义**：运行一次性命令。
4. 初始命令留空时，会使用该类型的默认命令。
5. 创建卡片。

双击卡片可进入聚焦终端。按 `Cmd/Ctrl + Shift + M` 返回卡片网格。

## 3. 将卡片固定到选择器

1. 返回卡片网格。
2. 找到卡片底部的操作按钮。
3. 点击图钉按钮。它的提示是 **固定到浮层选择器**。
4. 这张卡片现在可以出现在全局选择器、轮播模式和浮动终端中。

最多可以同时固定六张卡片。

AI CLI 卡片还带有意图菜单。可以把并行会话标记为审查、修复、研究、测试或文档，
这样多个 agent 同时运行时，网格仍然容易扫读。

## 4. 使用平铺和轮播模式

用下面的快捷键打开选择器：

```text
Cmd/Ctrl + Shift + Space
```

当主窗口处于焦点时，也可以使用：

```text
Cmd/Ctrl + `
```

在选择器中：

- 按 `M` 在平铺模式和轮播模式之间切换。
- 按方向键或 `Tab` 在已固定卡片之间移动。
- 按 `1` 到 `6` 直接选择对应卡片。
- 按 `Enter` 将当前卡片打开为浮动终端。
- 按 `Esc` 关闭选择器。

## 5. 验证通知

ThreadTerm 有两层通知：

- 应用内通知中心，可通过铃铛按钮或 `Cmd/Ctrl + B` 打开。
- 打包后的 Tauri 桌面应用会发送系统通知。

当会话需要处理或产生新回复时，点击通知会回到对应卡片。如果卡片已固定，
ThreadTerm 会直接在浮动终端中打开它；未固定的卡片会在主窗口中聚焦。

## 常见问题

| 现象 | 检查项 |
| --- | --- |
| AI CLI 卡片立即退出 | 确认对应 CLI 已安装，并且在 `PATH` 中可见。如果输出显示命令不存在，ThreadTerm 会在 Claude、Codex 和 Gemini 卡片上标出缺失 CLI。 |
| 全局快捷键打不开选择器 | 在设置中重新绑定快捷键，再切到主窗口外重试；macOS 上可能与 Spotlight 冲突。 |
| 没有系统通知 | 检查系统通知权限，并在设置里发送测试通知。 |
| 无法使用文件夹选择器 | 确认运行的是 Tauri 桌面应用，不是前端预览。 |
| Windows 打包前失败 | 安装 Visual Studio Build Tools 2022，并勾选 `Desktop development with C++` 工作负载。 |
