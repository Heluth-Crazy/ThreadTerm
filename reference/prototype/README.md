# ThreadTerm V3 桌面交互原型

从 `prototype/threadterm-app` 独立复制，保留主导航、侧栏层级、项目/工作树概览和工作区布局，补齐桌面交互。运行时使用本地资源，不需要启动 ThreadTerm、Tauri、Agent CLI 或模型服务。

## 启动

在仓库根目录执行：

```powershell
python -m http.server 4311 --bind 127.0.0.1 --directory prototype
```

打开 **http://127.0.0.1:4311/threadterm-app-v3/**。也可把本文件夹交给任意静态 HTTP 服务。请使用 HTTP 访问，以便浏览器保存草稿和下载文件。

## 从哪里体验

| 功能 | 入口与演示 |
| --- | --- |
| 创建会话 | 左上「新建终端」。Codex、Claude Code、Kimi、Gemini、OpenCode 都可选择 Terminal / Chat；另保留 Grok、Shell 和命令预设。 |
| Chat | 发送 → 增量回复 → 批准/拒绝工具请求；支持停止、模拟失败和重试。不提供 AI Markdown 下载。 |
| 生命周期 | 工作区配置、手动运行、模拟错误/完成；「结束会话」可演示正常结束、失败、超时、继续等待和强制结束。 |
| 历史 | 「所有终端」右侧栏默认是本机历史：扫描、取消、错误重试、筛选、分页、只读详情、导入卡片、明确选择恢复模式和缺失目录重新定位。点左侧卡片会改成该会话摘要，可用「本机历史」切回。 |
| 项目与工作树 | 侧栏点项目名进入项目主页：已关注「添加关注」、最近活动「查看全部」打开本地记录弹窗。指标带为 5 张计数卡 + 1 张用量卡，点「明细」打开筛选与估算。工作树菜单仍负责固定、排序、改名、归档/恢复、删除、创建/发现及移除保护。 |
| 编辑与差异 | 打开会话后切换「文件 / 差异」。CodeMirror 支持实际输入、保存、搜索替换、缩进、折叠、撤销重做、多文件草稿和冲突处理。 |
| 特殊文件 | 底部「演示数据」中的编辑器场景；可检查外部修改、只读、二进制、过大文件、读取失败和预览。 |
| 工作区与预设 | 并排最多四个同树会话，拖动/弹出/返回；预设可以跨树，命令需审阅后主动运行。 |
| 待处理与通知 | 通知铃、待处理页、关注清单。读通知不会批准工具请求；关注、书签和快捷选择固定分别保存。 |
| 设置 | 底部「本地用户 → 设置」。主题、语言、快捷键、通知、监督、数据包导入导出、迁移、设备及外部工具演示。 |
| 数据重置 | 底部「演示数据 → 重置 V3 演示数据」，确认后只清理本副本。 |

## 演示边界

所有会话、终端输出、文件、Git、迁移、移动设备与外部工具结果均为**合成数据**。保存写入浏览器的 `threadterm.app.v3`，不会修改项目文件。设置 JSON 只含白名单偏好，不是会话或设备的完整备份。

本轮包括桌面端移动连接管理；手机界面、真实网络/CLI/系统窗口、完整 IDE/LSP、VS Code、完整图形 Git、账户与支付不在本轮。价格、保留数量和商业权益仍是演示假设。

源副本带来的文档和 `preview/` 根目录旧截图保留作基线资料，其中历史产品状态不代表本次实现。**本轮以本 README、覆盖表及 `preview/v3/` 新验收资料为准**，包括后来明确批准的五类提供者双模式。
