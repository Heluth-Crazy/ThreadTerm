# Changelog

All notable changes to ThreadTerm will be documented in this file.

## 0.3.0 - 2026-04-26

- Established ThreadTerm as the desktop app name and package identity.
- Scoped the current product to project-bound terminal cards, global overlay selection, floating terminal sessions, theme packs, and OS notifications.
- Refined the public roadmap around the v0.2 stable AI CLI workbench milestone.
- Started v0.3 AI session workflow work with visible AI session badges and missing CLI diagnostics.
- Added AI card intent labels for review, fix, research, test, and docs workflows.
- Unified notification return paths so pinned AI cards open in the floating terminal and unpinned cards focus in the main window.
- Synchronized npm, Tauri, and Cargo package versions at 0.3.0.
